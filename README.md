# Memory Game

## Описание проекта
**Memory Game** — это интерактивная веб-игра на поиск пар карточек. Игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее количество ходов.

Приложение полностью создано с использованием чистых технологий **HTML, CSS и JavaScript (Vanilla JS)** без сторонних библиотек и фреймворков. Разметка генерируется динамически через `document.createElement`.

---

## Функциональность
- 🔀 **Случайная генерация полей:** 16 карточек (8 пар) перемешиваются по алгоритму Фишера — Йетса при каждой загрузке и перезапуске.
- 🎯 **Отслеживание прогресса:** подсчет ходов и найденных пар в реальном времени.
- 🏆 **Таблица лидеров:** сохранение 10 лучших результатов в `localStorage` с сортировкой по наименьшему числу ходов.
- 🪟 **Модальные окна:** универсальный компонент модальных окон (победа и таблица лидеров) с поддержкой закрытия по клику на оверлей, кнопке или клавише `Escape`.
- 📱 **Адаптивный дизайн и 3D-анимации:** плавный переворот карточек с помощью CSS 3D transforms.

---

## Требования к реализации (Ограничения)
- В исходном `index.html` тег `<body>` содержит только `<script>`.
- Весь интерфейс и элементы DOM создаются исключительно через `document.createElement`.
- Запрещено использование `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `alert`, `confirm`, `prompt`.
